# QVIT OS Webpage Assets Directory

Place your custom screenshots, mockups, or photos in this folder. The website is configured to look for the following file names:

1. **`boot_logo.png`** (or `.jpg`)
   - Description: Splash screen/boot logo representing QVIT OS.
   - Used in: The "What is QVIT OS?" / Plymouth Boot Logo placeholder box.

2. **`terminal_interface.png`** (or `.jpg`)
   - Description: Terminal prompt interface showing customized shell environments, conky widgets, or custom diagnostic details.
   - Used in: The "Quantum Command Center" terminal screenshot placeholder box.

3. **`desktop_dashboard.png`** (or `.jpg`)
   - Description: KDE Plasma desktop workspace interface, including widgets, open JupyterLab environments, or circuit visualizations.
   - Used in: The main "Hero Section" dashboard mockup placeholder box.

---
*Note: If you are using `.jpg` instead of `.png` files, you can update the corresponding `<img>` file extensions in the `index.html` file.*
